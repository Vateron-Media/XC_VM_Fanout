# Документация xc_fanout

**Язык:** Русский · [English](en/README.md)

`xc_fanout` — нативный Go-демон XC_VM для «раздачи» (fan-out) живых стримов:
**один процесс тянет каждый источник ровно один раз** и раздаёт его множеству
зрителей через nginx, держа PHP вне байтового тракта, и производит HLS
(в т.ч. с AES-128 шифрованием) **целиком в оперативной памяти**.

Документация разбита по темам — каждый файл описывает что-то одно. Если вы видите
проект впервые, читайте по порядку: 01 → 02 → дальше по интересу.

## Термины в одну строку

- **Поток (stream)** — один живой источник с идентификатором `<id>`, который демон раздаёт.
- **Fan-out** — раздача одного входящего потока множеству зрителей одновременно.
- **Puller** — часть, которая тянет источник (сама ходит за данными).
- **Ingest** — обратный режим: продюсер сам пушит данные демону.
- **Клиентская поверхность** — HTTP для зрителей (через nginx).
- **Управляющая поверхность** — HTTP только для PHP-панели (регистрация потоков, статус).
- **MPEG-TS** — транспортный формат видео, из 188-байтовых пакетов; базовый формат байтового тракта демона.
- **HLS** — потоковое вещание нарезкой на короткие сегменты + плейлист `.m3u8`.
